## 🇺🇸 English Version

Thank you for your interest in contributing to **Semaphore JS**! We welcome contributions of all forms, including bug fixes, new features, styling improvements, and documentation.

### 🚀 Getting Started

1.  **Fork** the repository and clone it to your local machine:
    ```bash
    git clone https://github.com/Luis-Carlos-Moraes/Semaphore-IA.git
    cd Semaphore-IA
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the application** in development mode:
    ```bash
    npm start
    ```

### 🧪 Running Tests

To ensure that your changes do not break existing logic, always run the automated test suite before submitting your code:
```bash
npm test
```
All test suites must pass successfully.

### 📝 Submission Process

1.  Create a new branch for your feature or bug fix:
    ```bash
    git checkout -b my-new-feature
    ```
2.  Commit your changes following clear, descriptive messages:
    ```bash
    git commit -m "feat: add horizontal theme config"
    ```
3.  Push your branch to your remote repository and open a **Pull Request (PR)** against the `production` branch.

## 🇧🇷 Versão em Português

Obrigado pelo seu interesse em contribuir para o **Semaphore JS**! Ficamos muito felizes em receber contribuições, seja corrigindo bugs, desenvolvendo novas funcionalidades, melhorando o estilo visual ou ajustando a documentação.

### 🚀 Começando

1.  **Faça um Fork** do repositório e clone-o em sua máquina local:
    ```bash
    git clone https://github.com/Luis-Carlos-Moraes/Semaphore-IA.git
    cd Semaphore-IA
    ```
2.  **Instale as dependências**:
    ```bash
    npm install
    ```
3.  **Execute a aplicação** em modo de desenvolvimento:
    ```bash
    npm start
    ```

### 🧪 Executando os Testes

Para garantir que suas alterações não quebrem a lógica existente, sempre execute a suíte de testes automatizados antes de enviar suas alterações:
```bash
npm test
```
Todos os testes precisam passar com sucesso.

### 📝 Processo de Envio

1.  Crie uma nova branch para a sua funcionalidade ou correção:
    ```bash
    git checkout -b minha-nova-funcionalidade
    ```
2.  Faça commits com mensagens claras e descritivas:
    ```bash
    git commit -m "feat: adiciona configuração de tema horizontal"
    ```
3.  Envie sua branch para o repositório remoto e abra um **Pull Request (PR)** direcionado para a branch `production`.
